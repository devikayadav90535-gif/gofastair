# Go Fast Air — Website Starter

A responsive courier/logistics website starter branded from the supplied Go Fast Air quotation artwork.

## Included
- `index.html` — complete responsive single-page website
- `style.css` — professional blue/navy logistics styling
- `script.js` — mobile menu, WhatsApp quote flow and demo tracking feedback
- `assets/gofastair-logo.jpg` — logo crop sourced from the supplied artwork

## Before production
1. Replace the logo crop with the original high-resolution transparent logo if available.
2. Connect the quote form to your preferred email/CRM/backend.
3. Replace the demo tracking message with your actual AWB/tracking API.
4. Confirm serviceable domestic locations, international destinations, rates and delivery timelines.
5. Add Privacy Policy, Terms & Conditions, cancellation/refund policy if applicable.
6. Add analytics and Search Console after deployment.
7. Test all phone, WhatsApp, email and tracking links on mobile and desktop.

## Deploy
Upload the contents of this folder to your hosting public web root (for example `public_html`) and point `gofastair.com` DNS to the hosting server.

No build step is required.
